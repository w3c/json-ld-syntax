## Agent Notes for `json-ld-syntax`

- **Source of truth for spec edits**
  - Modify **only** `index.html` for spec text and editorial changes.
  - Do not add `class="changed"` to new specification edits.
  - Treat files under `publication-snapshots/` (e.g., `publication-snapshots/*/Overview.html`) as **immutable snapshots** of published states.
  - Do **not** apply automated or manual spec edits to snapshot files unless explicitly instructed otherwise by a human maintainer.

- **Commit messages**
  - Commit messages must always be a single line.
  - Do not add co-authoring trailers (e.g., `Co-authored-by:`).
